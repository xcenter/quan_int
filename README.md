# Quan Int Application
Spring boot application developed for the Quan int.

## Executing tests
The application can be tested with the following command:
> ./mvnw clean test

## Building and running
The application can be built and run with the following commands:
> ./mvnw clean install
> docker-compose build
> docker-compose up

## Testing the application
The application can be manually tested by accessing the swagger-ui frontend at http://localhost:8080/swagger-ui.html
